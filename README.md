# 🏨 Sistema de Gestión de Habitaciones

Sistema integral para el control y gestión de 30 habitaciones con inventario sincronizado, observaciones de mantenimiento y reportes diarios.

## 📋 Características

✅ **Gestión de 30 Habitaciones**
- Control de 3 items principales: Control, Toallas, Llaves
- Estado: Disponible, Ocupada, Mantenimiento
- Asignación de responsables

✅ **Inventario de Almacén**
- Sincronización automática con habitaciones
- Registro de items en uso y dados de baja
- Control de existencias

✅ **Observaciones de Mantenimiento**
- Cuarto (pared, puerta, vidrios)
- Camas (sábanas, frazadas, sobresábanas)
- Muebles (roperos, mesas de noche)
- Electrónicos (teléfono, TV, lámparas, focos)
- Baño (inodoro, lavamanos, ducha)
- Otros

✅ **Funcionalidades**
- Botones: Agregar, Editar, Guardar, Borrar
- Búsqueda y filtrado
- Reportes diarios imprimibles
- Interfaz intuitiva con VBA
- Alertas y validaciones

## 📥 Descarga

Descarga el archivo `Sistema_Gestion_Habitaciones.xlsm` para usar inmediatamente.

## 🚀 Instrucciones de Uso

1. Descargar el archivo `.xlsm`
2. Habilitar macros de VBA cuando abra el archivo
3. Comenzar con el Dashboard
4. Gestionar habitaciones, inventario y observaciones

## ⚙️ Requisitos

- Microsoft Excel 2016 o superior
- VBA habilitado
- Habilitar marco de confianza para ejecutar macros

## 📖 Módulos VBA Incluidos

- `ModuloDashboard` - Interfaz principal
- `ModuloHabitaciones` - CRUD de habitaciones
- `ModuloInventario` - Gestión de almacén
- `ModuloObservaciones` - Mantenimiento
- `ModuloReportes` - Generación de reportes
- `ModuloValidacion` - Controles y alertas
